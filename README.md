# travel-alerts-ke

Source registry and integration notes for Travel Alerts.ke, which publishes verified travel alerts for Africa first, then global.

## Contents
- [SOURCES.md](SOURCES.md) — curated starting directory for research: official authorities, media, regional bodies, and weather and natural-hazard sources.
- [PIPPIT_BRIDGE.md](PIPPIT_BRIDGE.md) — image/video generation adapter: setup routes, security requirements and deployment status (documented; not yet installed).

## Governing instructions
Research rules live in the [Chatgpt.-Md](https://github.com/siiro-byte/Chatgpt.-Md) repository: [CHATGPT.md](https://github.com/siiro-byte/Chatgpt.-Md/blob/main/CHATGPT.md) and [TRAVELALERTS_RESEARCH.md](https://github.com/siiro-byte/Chatgpt.-Md/blob/main/TRAVELALERTS_RESEARCH.md). A source being listed here does not mean its information is current or verified.
